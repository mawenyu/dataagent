## 方法
按修正后的 DELIVERY-README §0-§3 从零重建：干净 clone 主仓库 → fork 源码 bun install → build-opencode.sh 部署扩展 → tsconfig.json/密钥带外注入 → mvn package → npm install+build+test → 起服务 → 健康检查 + 真链路回归。

## 环境偏差（如实记录）
1. GitHub 大传输当日被限速（~30KB/s，多次 depth1 clone/codeload tarball 均中途 reset；git ls-remote 秒回证明仓库可达）。fork 源码改从本机镜像 git archive d5d737f（= origin/dataagent-v2 head，ls-remote 已核对一致）导出，其余步骤不变。
2. 本机 4096/8090/3001 被共享在跑实例占用（CLAUDE.md 共享纪律不动它们）。干净 clone 起的服务用 4196/8190 验证（SERVER_PORT/OPENCODE_SERVER_URL 环境覆盖）；8090 健康为在跑实例实测。
3. ~/.m2 与 bun/npm 缓存为温热（全新机器首次构建会更慢，不影响结论）。密钥（.env.opencode / opencode.jsonc apiKey）按文档口径带外注入——干净机器上由部署人提供，本测试从主仓本机拷贝。
