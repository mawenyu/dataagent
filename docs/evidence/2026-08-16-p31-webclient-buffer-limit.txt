P31 长会话历史加载 256KB 缓冲截杀修复 —— 证据（2026-08-16 17:45 CST）
=====================================================================

【发现（audit 自 gateway.log）】
2026-08-16 05:45 生产日志：ChatThreadsController 加载 thread vision-p6-form
历史失败 —— DataBufferLimitException: Exceeded limit on max bytes to buffer
: 262144。根因：gateway WebClient 未配置 maxInMemorySize（默认 256KB），
多 A2UI surface 的长会话历史 JSON 轻易超限 → 前端点开老长会话拿不到历史。

【TDD 红→绿（gateway/src/test/.../WebClientConfigTest.java）】
红（反证）：JDK HttpServer 真实回 512KB 响应体 + 显式 262144 上限 →
  完整复现生产异常 WebClientResponseException ← DataBufferLimitException
  "Exceeded limit on max bytes to buffer : 262144"（Tests run: 4, Errors: 1）
绿：默认路径（0 = DEFAULT_MAX_IN_MEMORY_SIZE 8MB）完整读出 512KB+；
  显式 64KB 上限仍拒绝 512KB 响应（保护语义不丢）。

【修复】
WebClientConfig：.codecs(c -> c.defaultCodecs().maxInMemorySize(limit))；
opencode.server.max-in-memory-size 可配，0/缺省 = 8MB 常量（消灭注解字面量
与常量双写漂移）。
